Combining Like Terms

How to Combining Like Terms

Hello, this is Wyatt, and today we're going to be talking about combining like terms in seventh-grade algebra. Let's get right to it!

Problem 1

r − 24r

We want to simplify this by combining like terms.

When we're combining like terms, we first look for common variables, which is r in this case. Then we look at the coefficients.

Notice that the first r doesn't appear to have a coefficient, but it actually does. We can think of it as 1r.

So the expression becomes:

1r − 24r

Since both terms have the same variable, we only subtract the coefficients:

1 − 24 = −23
Answer: −23r

Problem 2

5/8h² + 60 − 3/4h²

Variables with exponents can only be combined if both the variable and the exponent are exactly the same.

Since 60 is a constant, it cannot be combined with the h² terms.

Rewrite the expression:

5/8h² − 3/4h² + 60

Convert 3/4 into eighths:

3/4 = 6/8

Now subtract:

5/8 − 6/8 = −1/8
Answer: −1/8h² + 60

Problem 3

18y² − 4y² + y

Remember, only terms with the same variable and the same exponent can be combined.

The term y is really y¹, so it cannot be combined with y².

Now combine the y² terms:

18 − 4 = 14
Answer: 14y² + y

Challenge Problem

√z + z² × z³ − 60 + yz

Use the order of operations (PEMDAS).

Multiply first:

z² × z³ = z⁵

The expression becomes:

√z + z⁵ − 60 + yz

None of these terms are like terms, so no further combining can be done.

Answer: √z + z⁵ − 60 + yz

Thanks for Watching!

That is how you combine like terms in seventh-grade algebra.
